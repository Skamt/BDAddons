# The stuff of the BetterDiscord

## Plugins
- [CopyImageLink](https://github.com/Skamt/BDAddons/tree/main/CopyImageLink) - Adds (Copy Link) button next to (Open Original) under images. 
- [Devtools](https://github.com/Skamt/BDAddons/tree/main/Devtools) - A set of debugging/DX tools.
- [Emojis](https://github.com/Skamt/BDAddons/tree/main/Emojis) - Send emoji as link if it can't be sent it normally.
- [FloatingChannels](https://github.com/Skamt/BDAddons/tree/main/FloatingChannels) - Open channls in floating window.
- [HideStuff](https://github.com/Skamt/BDAddons/tree/main/HideStuff) - Hide Stuff using Element picker.
- [LazyLoadChannels](https://github.com/Skamt/BDAddons/tree/main/LazyLoadChannels) - Lets you choose whether to load a channel.
- [NoAutoUnread](https://github.com/Skamt/BDAddons/tree/main/NoAutoUnread) -- [source](https://github.com/Equicord/Equicord/tree/main/src/equicordplugins/stopAutoUnread)
- [NoProfileThemes](https://github.com/Skamt/BDAddons/tree/main/NoProfileThemes) -- [source](https://github.com/Vendicated/Vencord/tree/main/src/plugins/noProfileThemes) - Removes Nitro profile themes. 
- [NoPushToTalk](https://github.com/Skamt/BDAddons/tree/main/NoPushToTalk) -- [source](github.com/Equicord/Equicord/tree/main/src/equicordplugins/noPushToTalk)
- [NotificationVolume](https://github.com/Skamt/BDAddons/tree/main/NotificationVolume) -- [source](https://github.com/Vendicated/Vencord/tree/main/src/plugins/notificationVolume) - set a volume for notifications and in-app sounds. 
- [Quests](https://github.com/Skamt/BDAddons/tree/main/Quests) - Solve Quests based on [aamiaa script](https://gist.github.com/aamiaa/204cd9d42013ded9faf646fae7f89fbb).
- [SendStickersAsLinks](https://github.com/Skamt/BDAddons/tree/main/SendStickersAsLinks) - Send custom Stickers as links, (custom stickers as in the ones added by servers. **not officiel discord stickers**).
- [SpotifyEnhance](https://github.com/Skamt/BDAddons/tree/main/SpotifyEnhance) - All in one better spotify-discord experience.
- [StickerEmojiPreview](https://github.com/Skamt/BDAddons/tree/main/StickerEmojiPreview) - Adds a zoomed preview to those tiny Stickers and Emojis.
- [Tabbys](https://github.com/Skamt/BDAddons/tree/main/Tabbys) - Adds Browser like tabs/bookmarks for channels. 
- [ViewProfilePicture](https://github.com/Skamt/BDAddons/tree/main/ViewProfilePicture) - Adds a button to the user popout and profile, allows you to open up the Avatar and banner.
